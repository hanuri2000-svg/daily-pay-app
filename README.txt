[일당 계산기 웹앱]

구성 파일
- index.html: 앱 본체
- manifest.webmanifest: 홈 화면 앱 설정
- sw.js: 오프라인 실행용
- icon.svg: 앱 아이콘

중요
아이폰에서 '앱처럼 설치'하려면 이 폴더를 웹서버(예: GitHub Pages, Netlify)에 올려 HTTPS 주소로 접속해야 합니다.
파일 앱에서 index.html을 직접 여는 방식은 저장/설치 기능이 제한될 수 있습니다.

아이폰 설치
1. 배포된 HTTPS 주소를 Safari로 열기
2. 하단 공유 버튼 누르기
3. '홈 화면에 추가' 선택
4. 홈 화면의 '일당계산' 아이콘으로 실행

데이터
- 기록은 Safari의 로컬 저장소에 자동 저장됩니다.
- 설정 > 백업 파일 저장으로 JSON 백업을 보관하세요.
- 브라우저 데이터 삭제나 기기 교체 전에 반드시 백업하세요.
